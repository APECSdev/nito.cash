How it works

  • Shield — deposit PUSD into a covenant pool; the deposit is public, the resulting note is not.
  • Pay privately — every transfer is a single ~37 KB transaction carrying a Groth16 proof with exactly 2 public inputs [merkleRoot, actionHash] (~183k constraints); nullifiers + fresh commitments are private witnesses.
  • Covenant-carried state — {merkleRoot, nullifierSet} rides in a CashToken NFT commitment; replay is stopped on-chain.
  • Unshield — withdraw to a public address; the payout amount is visible again.

Under the hood

  • Keys never leave the device — BIP39/BIP32 derivation + Schnorr signing locally (libauth).
  • Sealed note store — AES-256-GCM via WebCrypto; only ciphertext persists.
  • In-browser proving — snarkjs WASM Groth16; no proving server.
  • No single point of trust — a quorum (2) of Fulcrum servers must agree on every response (default server: chipnet.bch.ninja).
  • Trusted setup — phase 1 reuses the public Perpetual Powers of Tau (86 contributors); phase 2 is a disclosed 1-of-1 placeholder — a full MPC ceremony is mandatory before any mainnet value.
